fix(i18n): make the word grid English-only; Indonesian uses flowing text

Gitar's second review was right that a fixed 5x5 matrix cannot spell Indonesian
out: the phrase order varies by case (JAM TIGA LEBIH SEPULUH vs JAM SETENGAH
EMPAT), and WordGrid.activeCells matches by key with no notion of position, so a
DUA cell would light for both the hour and the tens word.

Rather than a fragile grid, the honest model is that a word grid is a physical
layout only some languages have. TimeLocalization.gridWords() now returns null
for a language without a grid, LocalizationRegistry exposes gridOrNull(), and the
widget falls back to flowing text. English keeps its grid unchanged; Indonesian
renders as correct flowing text. The config screen notes the grid is English-only.

Removes IndonesianWordGrid and its key-order test.
